# 物質介紹編輯規範與 MDX 維護

本文件是專案物質介紹頁面的詳細編輯規範，適用於 `/learn` 中的物質介紹頁面及對應內容的生成、擴寫、改寫與審查。開始工作前必須讀取本文件；完成後必須依「完稿檢查表」逐段審查實際成稿並修正問題，不能以格式或自動測試通過取代內容審查。

固定章節、MDX 正文、保留人工編輯及沿用既有 shadcn 元件與主題色彩的要求，仍依專案根目錄的 [AGENTS.md](../../AGENTS.md)。目前 MDX 實作包含 `/learn/mdma`、`/learn/5-meo-dmt`、`/learn/lsd` 與 `/learn/psilocybin`，本規範也適用於之後新增或遷移的物質頁面。

知識指南入口為 `/learn`，物質介紹直接使用 `/learn/<slug>`；舊 `/substances` 與其子網址已移除，不提供轉址。本文件的固定七章規則適用於物質介紹，不預設其他主題文章也採相同章節。

## 文章目標

面向一般讀者，使用繁體中文，以研究本身為中心。正文優先呈現「研究問題 → 關鍵設計 → 具體結果」，讓讀者知道研究想回答什麼、如何研究，以及實際發現什麼。說完結果即可結束段落，不預設還要補上研究意義、限制、外推提醒或編輯總結。

以讀者能否準確理解研究作為編輯判準，不以字數更少作為改善標準。基本認識與歷史等背景內容可直接陳述已核對的事實，不必套用研究敘述順序。

## 編輯規範

### 研究描述與段落組織

- 每項重要研究交代研究問題、理解結果所需的設計，以及具體發現。依內容安排自然的句子，不必逐一標示「問題／方法／結果」，也不必機械填滿所有研究欄位。
- 段落可以只介紹一項研究，並在結果及其引用後結束。另一項研究若確實探討相關問題，可以自然接續；沒有值得說明的關係時，直接換段介紹下一項研究。
- 不要求每段整合多篇研究、解釋共同意義或加入總結。不要為了連貫而創造原文沒有支持的因果、比較或共同結論。
- 用研究主題及具體條件承接內容，減少「若把問題從……擴展到……」「接下來討論……」等描述敘述過程的轉場，也不只靠添加「此外／然而」串接。
- 已符合目標的段落採局部編輯，保留準確的研究條件、結果與引用。修改範圍依實際問題及使用者要求決定，不為追求更短或更流暢而反覆重組全文。

### 研究之間的關係

- 接續相關研究時，核對研究問題、疾病、族群、介入、比較組、結果指標、時間點及設計，只說明有助理解的條件與結果異同。不同問題不直接視為彼此支持或反駁。
- 只有真正存在對照或矛盾時才使用「但是／然而」。沒有可比較的關係時，分段陳述即可，不必補寫兩項研究的共同意義。
- 不得把不同試驗的結果自行換算成兩種治療的優劣。只有直接比較兩種治療，且結果指標與時間點清楚的研究，才能支持相應的療效比較。
- 在研究描述中區分物質本身、搭配心理治療的介入及自然使用情境，不把其中一種情境的結果改寫為另一種情境的效果。
- 新增文獻時，檢查受影響的段落並兼顧支持、未達統計顯著及相反的發現；依各研究的問題與設計呈現，不為得到一致結論而忽略不同結果。

### 研究條件、文字與數值

- `healthy volunteer` 統一譯為「健康受試者（Healthy Volunteer）」，不用「健康志願者／志願者」；每頁首次出現時可附英文，後續簡稱「健康受試者」。若來源只寫 volunteer、未確認健康條件，稱「受試者」，不自行加上健康限定。原文摘錄與英文書目維持來源原文。
- 依理解需要選擇族群、樣本數、介入方式、劑量、是否搭配心理治療、比較組、追蹤時間及結果數字。保留會改變結果含義的條件，其餘細節可留在內部證據筆記。
- 以物質與研究問題為句子的主體。作者姓名、調查名稱及年份僅在有助理解時保留，例如辨識證據年代；引用綜述時須保留綜述層級，不冒稱已獨立讀取其中的原始研究。
- 研究設計是結果的一部分，不等於要在正文講解方法學。正文交代實際如何研究即可，不習慣性追加「這提醒我們……」「這些結果不能直接套用……」「仍需更多研究……」等評論。
- OR（勝算比）、HR（危險比）等數值若有助理解，可簡潔保留。不得將它們直接寫成機率、絕對風險、絕對風險變化或治療效果，也不將未達統計顯著寫成完全無效。
- 同一結果不必以百分比與比值重複報告。統計定義、完整區間及詳細解釋保存在內部證據筆記；不為保留數字而展開統計教學，也不必為此新增介面。

### 必要限定與完整限制的分工

- 不預設每段都需要研究限制、方法學解說、外推提醒或總結。即使論文討論中提到某項限制，也不代表它應出現在正文；只有省略會直接扭曲該項結果時，才保留最簡短的必要限定。
- 必要限定優先融入研究描述。例如觀察研究直接寫「使用史與某結果相關」，並交代所需的族群或比較組；不要先寫成因果，再用一整句「不能推論因果」補救。
- 不要求在段末集中補寫限制，也不要求把共通提醒移到別章後一定保留。只有研究描述本身仍無法避免具體誤解時，才在相關主張附近補一句必要說明；說明應直接對應該結果。
- 完整的研究限制、方法學疑慮及外推注意事項保存在內部證據筆記。正文未使用某項提醒，不代表應刪除其證據紀錄，也不代表可以加強結論。
- 區分「研究本身判斷證據不足」與「本頁尚未收集足夠文獻」。前者可以作為綜述的具體結果，但須保留其問題範圍與年代；後者記入內部資料缺口，不放在頁面開頭，也不概括成整個領域沒有證據。

### 來源與引用

- 行內引用緊接它支持的具體研究內容，且能回查原文位置。一句涉及不同來源的主張時，分別放置引用，不以一個段末引用包辦多個來源。
- 引用用來支持研究問題、設計與結果，不能代替內容取捨。某項提醒即使有 citation 或已存為 evidence，也不因此成為正文必收內容。
- 只引用實際讀取並核對過的來源，不補造數字、DOI、原文位置或研究結論。移動、合併或改寫後，重新核對來源是否支持完整敘述，包括研究條件、數值、方向與時間點。
- 保留既有 `GuideSection`、`Cite`、`RelatedPapers`、`References` 元件及 evidence ID 對應機制。正文刪去提醒時，可一併移除該句的引用元件；保留仍支持研究內容的引用及證據紀錄，不為了保留全部 citation 而留下無必要的句子。編號由既有功能產生。
- 缺少來源時記錄資料缺口，不為填滿固定章節而加入牽強內容。頁面收錄範圍、尚缺文獻及正文未涵蓋的問題，保存在內部證據筆記；既有證據快照的 `scopeNote` 僅供內部維護，不在公開介紹頁顯示。

### 公開頁面與內部查核資料

- 公開介紹頁不在開頭顯示「資料範圍」區塊；純文字稿也遵循相同原則。
- 保留正文行內編號及文末參考文獻。公開書目只顯示編號、論文標題、作者、期刊與年份；網站可保留連到本站 paper 頁面的標題連結。
- 參考文獻不顯示原文定位、引用依據（含原文摘錄、證據展開內容）或 DOI 外連結；純文字稿的書目也不附 DOI。
- DOI、PDF 頁碼、原文摘錄、evidence ID、研究條件及完整限制仍保存在內部證據資料中，供生成、更新與審查時核對。公開顯示簡化不降低來源查核要求。

## 正反例：全部為假設內容

以下的物質 X、疾病甲、量表甲及「假設來源 A–D」都是教學用的假設內容，不代表真實醫學主張或文獻，也不是可用的 evidence ID。正例僅在所列假設條件下成立。

### 一、交代研究問題、設計與結果，說完即可結束

假設條件：來源 A 招募疾病甲的成年患者，直接比較物質 X 搭配心理治療與安慰劑搭配相同心理治療，四週後以量表甲評估症狀；物質 X 組的量表表現優於對照組。

**原寫法**：研究 A 發現物質 X 有效。[假設來源 A] 這項結果為治療帶來重要啟示，仍需更多研究確認。

**改善寫法**：一項試驗評估在心理治療中加入物質 X 是否改善疾病甲的症狀，將成年患者分為物質 X 與安慰劑兩組，兩組接受相同心理治療。四週後，物質 X 組的症狀量表表現優於安慰劑組。[假設來源 A]

**改善原因**：補足研究想回答的問題、介入與比較條件，讓「有效」成為有指標及時間點的具體結果；結果後即可結束，不追加評語。

### 二、把必要限定寫進研究描述

假設條件：來源 C 是成年自然使用者的橫斷面問卷調查，只報告物質 X 使用史與症狀量表分數的關聯。

**原寫法**：物質 X 能減輕疾病甲症狀。[假設來源 C] 但是這項研究不能推論因果，因此不能當成治療效果。

**改善寫法**：一項成人橫斷面問卷調查比較物質 X 使用史與疾病甲症狀，發現有使用史者的症狀量表分數較低，兩者呈現關聯。[假設來源 C]

**改善原因**：以觀察研究的實際設計與關聯語氣呈現結果，不先寫成療效再補救。完整限制仍保存在證據筆記，不必逐項搬入正文。

### 三、有具體關係時再接續研究

假設條件：來源 B 與 A 採用相同族群、介入、比較方式、四週評估時間點及量表，並明確報告基線症狀較重者的改善更明顯。

**原寫法**：研究 A 發現症狀改善，研究 B 也有重要發現。[假設來源 A][假設來源 B] 這提醒我們，每位患者都不一樣。

**改善寫法**：物質 X 搭配心理治療組在四週後的症狀量表表現優於安慰劑搭配相同心理治療組。[假設來源 A] 另一項採相同介入與比較方式的試驗進一步分析基線症狀程度，發現症狀較重者的改善更明顯。[假設來源 B]

**改善原因**：接續的是同一研究問題中的具體條件差異，結果已交代兩項研究的關係，不需要再總結共同意義；單篇研究也可獨立成段。

### 四、不同問題可以直接分段

假設條件：來源 A 如上；來源 D 評估健康成人單次給藥後的記憶測驗，與對照組的差異未達統計顯著。

**原寫法**：物質 X 搭配心理治療改善疾病甲症狀。[假設來源 A] 然而，另一項研究發現物質 X 對健康成人記憶完全無效。[假設來源 D] 這些結果顯示作用仍不一致。

**改善寫法**：疾病甲的成年患者接受物質 X 搭配心理治療後，四週後的症狀量表表現優於安慰劑搭配相同心理治療組。[假設來源 A]

另一項研究評估健康成人單次給藥後的記憶表現，記憶測驗與對照組的差異未達統計顯著。[假設來源 D]

**改善原因**：兩項研究的族群、介入及結果指標不同，直接分段即可；不製造矛盾、不把未顯著寫成無效，也不強行歸納共同結論。

## 完稿檢查表

檢查實際成稿及受修改影響的段落，不以格式或自動測試通過取代內容審查。通讀整頁，確認資訊取捨符合研究問題，而非為套用段落模板增刪內容。

- [ ] **研究內容**：每項重要研究是否交代想回答的問題、理解所需的設計與具體結果？族群、介入、比較組、時間點及數值是否依需要選取，沒有機械填滿或刪去關鍵條件？
- [ ] **段落結尾**：結果之後是否習慣性追加提醒、方法學說明或編輯總結？省略後若不扭曲結果，是否已從正文移除？
- [ ] **必要限定**：是否優先以「相關」、研究族群、設計及比較條件準確描述結果？是否把關聯寫成因果、未顯著寫成無效，或先加強主張再靠警語補救？
- [ ] **研究關係**：接續研究時是否有具體且有來源的關係？不同問題是否可直接分段，沒有強行轉折、合併意義或跨試驗比較療效？
- [ ] **數值與引用**：數字、指標、方向及時間點是否準確，沒有混淆 OR、HR、機率與絕對風險？每個引用是否仍支持相鄰研究內容，沒有只因提醒有 citation 就將它保留？
- [ ] **限制與內部資料缺口**：正文只保留省略會直接扭曲結果的最短限定嗎？完整限制是否仍在證據紀錄中？研究本身的證據不足判斷與頁面收錄缺口是否分清，後者是否記入內部筆記，而非顯示在頁面開頭？
- [ ] **全文與結構**：是否保留準確的研究條件、結果、必要引用及固定章節？段落是否可自然讀完，沒有不必要的跨章節重複或為縮短而重組已合適的內容？公開頁面及純文字稿是否已移除開頭資料範圍、書目原文定位、引用依據與 DOI 外連結？

檢查出問題時直接修正，再重讀相關段落並核對引用。無法解決的來源缺口須明確回報涉及的研究內容、缺少哪種來源或原文資訊，以及仍無法支持的結論；將頁面收錄缺口記入內部證據筆記，不用推測填補。

## MDX 正文與引用格式

依序使用七個 `GuideSection`，每個區塊由對應的二級標題開始：

```mdx
<GuideSection id="benefits">

## 潛在益處

研究結果的敘述。<Cite evidence="jones-nock-2022-mdma-ideation" />

</GuideSection>
```

同一句話需要同篇 paper 的數筆證據時，用空格分隔，顯示一次文獻編號：

```mdx
研究結果與其限制。<Cite evidence="jones-nock-2022-mdma-ideation jones-nock-2022-design-limit" />
```

不同 paper 使用各自的 `Cite`。編號依首次出現順序產生，重複引用同篇沿用編號。正文引用會跳到文末書目，標題連到本站 paper 頁面。原文、PDF 頁碼、研究條件、結果與限制仍透過 evidence ID 在內部證據快照中核對，不在公開書目展開；書目不提供 DOI 外連結。

延伸閱讀章節使用 `<RelatedPapers />`，參考文獻章節使用 `<References />`。編譯器檢查章節順序、來源是否存在、審閱狀態、物質／章節適用範圍，並拒絕缺少文末書目的內容。

只編譯專案內已審閱的 MDX；不要把 PDF 文字、使用者輸入或任意 CMS 內容直接當作 MDX 執行。目前的編輯格式不接受 JavaScript 表達式、import/export 或未支援的 JSX 元件。

## 原文核對

`source.pdfPage` 使用包含封面的 PDF 實體頁碼，從 1 起算。每篇文獻的 `source.sha256` 指定實際核對的檔案版本。文獻綜述的樣本數為 `null`，不以研究篇數冒充受試者人數；未報告的統計資料也保留空值。量化結果區分 OR、aOR、HR 與 Cohen's d，保存原文報告的信賴水準及區間。

MDMA 正文依發布快照中已核對的九篇文獻撰寫，包含 2022 年小鼠劑量反應實驗及 2025 年 MDMA 輔助治療綜述；不把觀察研究或動物測驗寫成人類治療效果，也不以 2015 年綜述代替後續臨床試驗或監管狀態的查核。2025 年綜述的來源身分、轉述層級與本次編輯審查見 [Wolfgang 2025 收錄紀錄](wolfgang-2025-mdma-review.md)。其他新增研究的 DOI 更正關係、方法與原文定位見 [Pantoni 2022 收錄紀錄](pantoni-2022-dose-analysis.md)。線上書目核對來源包括 PubMed： [Jones 2023](https://pubmed.ncbi.nlm.nih.gov/36314881/)、 [Jones & Nock 2022](https://pubmed.ncbi.nlm.nih.gov/34983249/)、 [McCardle 2004](https://pubmed.ncbi.nlm.nih.gov/15088077/)、 [Taurah 2014](https://pubmed.ncbi.nlm.nih.gov/24114426/)、 [Huizink 2006](https://pubmed.ncbi.nlm.nih.gov/16500927/)、 [Patel & Titheradge 2015](https://pubmed.ncbi.nlm.nih.gov/26199721/)、 [Guillot 2007](https://pubmed.ncbi.nlm.nih.gov/17523583/)。此書目核對不代表已完成完整的更正／撤稿或研究品質審查。

## 匯入後台

先檢查關聯與預計新增數量：

```sh
pnpm import:substance-evidence
```

確定後新增尚不存在的證據：

```sh
pnpm import:substance-evidence -- --apply
```

指令以正規化 DOI 比對既有 paper，全部來源能唯一對應且連結一致才開始新增。若 CMS 有歷史重複 DOI，可在經人工核對的書目加入 `cmsId` 固定所選紀錄；ID、正規化 DOI 與 slug 必須同時符合，未指定 ID 的歧義仍會拒絕匯入。以固定證據鍵判斷是否存在，保留既有後台編輯，不執行資料庫清除或原文獻修改，也不設定或發送郵件。原始 PDF 不上傳到 Payload。

預設處理 MDMA；其他物質使用 `--slug`，例如：

```sh
pnpm import:substance-evidence -- --slug psilocybin
pnpm import:substance-evidence -- --slug psilocybin --apply
```

## 驗證

```sh
pnpm test:substances
```

使用有 `pypdf` 的 Python 環境，核對發布快照中的全部原文定位：

```sh
python3 scripts/verify-substance-papers.py --pdf-dir /path/to/psychedelics-papers-of-database --guide-evidence content/substances/mdma.evidence.json
```

LSD 的來源核對使用同一指令，將 `--guide-evidence` 改為 `content/substances/lsd.evidence.json`。查核時保留標示劑量與實測含量的差別、給藥場次與人數的差別，以及各合併分析的資料重疊；機制研究不冒稱直接測試 LSD 臨床療效。

Psilocybin 的來源核對使用同一指令，將 `--guide-evidence` 改為 `content/substances/psilocybin.evidence.json`。癌症追蹤的兩份 PDF 只收錄一筆來源；同一癌症方案的質性訪談及 AUD 母試驗的人格次級分析不當作獨立療效複現。

5-MeO-DMT 的來源核對使用同一指令，將 `--guide-evidence` 改為 `content/substances/5-meo-dmt.evidence.json`。其內容區分自然情境觀察、單一病例、合併 ibogaine 的整套方案、化學分析及機制綜述；不得將機制假說或合併介入結果改寫成單獨使用的臨床療效。

原始七篇測試清單及圖表擷取限制仍保存在 `pilot-papers.json` 與本目錄的 `README.md`。
